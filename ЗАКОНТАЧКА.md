# Законтачка

Законтачка - основная подсистема децентрала, цель которой - предоставлять возможность пиринга с другими узлами сети.

MVP: ping и pong с другими узлами сети. NAT не должен мешать этому процессу.

В идеале, законтачка должна позволять обмениваться сообщениями с другими узлами сети.

## Общая архитектура

Имеется исполняемый файл "агент", который позволяет подключиться к оверлею сети и заполнить локальные бакеты уже существующих узлов. После этого, контакт может быть использован для поиска других узлов сети и обмена с ними сообщениями.

Каждая нода сети имеет пару ключей Ed25519, которые используются для идентификации ноды и шифрования сообщений. Публичный ключ ноды используется в качестве идентификатора ноды в сети.

Оператор-нода сети транслирует сообщения в сеть, используя публичные ключи других узлов для шифрования сообщений, а также постквантово защищённую подпись ML-DSA-56 для своих сообщений.

## Требования

1. Для подключения и состояния узла использовать Kademlia DHT
1. Агент должен являться минималистичным и самодостаточным
1. P2P пинг должен работать даже при наличии NAT
1. Сообщения должны быть зашифрованы с использованием ключей Ed25519
1. Оператор-нода должна использовать постквантовую подпись ML-DSA-56 для своих сообщений

## UseCases

### UseCase: авторизация узлов

1. Оператор подписывает сертификат публичного ключа ноды с помощью ML-DSA-56 и рассылает его в сеть, подписываясь своим ключом
1. Узлы сети проверяют подпись сертификата и добавляют публичный ключ ноды в свои локальные бакеты доверенных нод, если подпись верна
